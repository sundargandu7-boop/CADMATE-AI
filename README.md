# CADMATE-AI
AI-powered mechanincal CAD design assisatant
CADMate AI is a prototype assistant designed to help mechanical engineering students and CAD beginners with basic mechanical design, material selection, manufacturing guidance, and AutoCAD workflows.

### Features

- Mechanical component selection
- Basic design and dimension guidance
- Material recommendations
- Manufacturing process suggestions
- AutoCAD drawing guidance
- Interactive question-and-answer interface

### Supported Components

- Gear
- Flange Coupling
- Shaft
- Bearing
- Pulley

### Technology

- Python
- Gradio
- Google Colab
- GitHub

### How It Works

1. Select a mechanical component.
2. Enter a design-related question.
3. Click **Analyze Design**.
4. CADMate AI provides design guidance.

### Future Improvements

- Real AI/LLM integration
- Automatic CAD/DXF generation
- Engineering calculations
- Design validation
- Material database
- Manufacturing cost estimation

### Disclaimer

This project is an educational prototype. Engineering recommendations should be reviewed by a qualified engineer before real-world manufacturing or safety-critical use.

### Project Goal

To combine **Artificial Intelligence + Mechanical Engineering + CAD** into a simple assistant for students and beginner designers.
